# JourneyTrace

A privacy-first, browser-only Google Timeline visualizer. Timeline data never leaves the device; map tiles are the only network dependency.

JourneyTrace is inspired by and based on the open-source [Timeline Visualizer](https://github.com/mahlernim/google-timeline-visualizer) project by mahlernim. The original project uses the MIT License.

## Development

```bash
npm install
npm run dev -- --host 0.0.0.0
```

Run checks with:

```bash
npm test
npm run build
```
